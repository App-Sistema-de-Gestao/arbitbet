ARBITBET PWA — ATUALIZAÇÃO 2

Novidades: menu retrátil, edição de casas/contas, edição de entradas, entradas criadas sempre como PENDENTE e finalização no painel por GREEN, RED, REEMBOLSO ou CASHOUT. Cashout exige valor recebido; P&L = recebido - stake. Calendário e P&L usam a data da finalização para operações novas.

Para instalar: publique os arquivos em HTTPS (por exemplo, Vercel). Abra no Chrome/Edge e escolha Instalar; no iPhone, Compartilhar > Adicionar à Tela de Início.

ATENÇÃO: autenticação apenas local, não segura para internet pública; dados não sincronizam entre dispositivos. Faça backup JSON. Casas e resultados fictícios já existentes no protótipo são apenas exemplos; não representam dinheiro real. Arbitragem com múltiplas pernas ainda não é suportada. Evite publicar dados financeiros reais até integrar login e banco seguro.
